# DeltabotProject

Repo for the Deltabot graduate project.
Goal: train a neural network to do inverse kinematics for a 3D printed deltabot driven by 3 stepper motors.

More information on the Deltabot can be found here https://github.com/garethnisbet/DeltabotController 

The Camera Software used to track the movement of the bot is here https://github.com/garethnisbet/MicroscopeViewer
